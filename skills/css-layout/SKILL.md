تخطيط الصفحات بـ CSS والتصميم المتجاوب وحل مشكلات التنسيق.

## الخطوات
1. اختر حسب الاتجاه: Flexbox لاتجاه واحد (صف أزرار، شريط تنقل)، وGrid لاتجاهين (تخطيط الصفحة، معارض البطاقات). باعد العناصر بـ `gap` بدل الهوامش.
2. التوسيط: `display: grid; place-items: center;` على العنصر الأب يوسّط في الاتجاهين، و`margin-inline: auto` يوسّط كتلة بعرض محدد، و`text-align: center` يوسّط النص.
3. متجاوب من الأساس: أنماط الجوال أولًا، ثم استعلامات `min-width` عند نقاط انكسار المحتوى (نحو 640 و768 و1024 و1280 بكسل). الأحجام المرنة بـ `clamp()` و`minmax()` و`repeat(auto-fit, minmax(16rem, 1fr))` تلغي نقاط انكسار كثيرة، واستعلامات الحاوية تضبط المكوّن بعرضه هو.
4. الوحدات: `rem` للخط والمسافات، و`%` أو `fr` للعروض، و`dvh` بدل `vh` للأقسام بكامل الارتفاع على الجوال، وعرض أقصى بين 60 و75 حرفًا لنصوص القراءة.
5. نموذج الصندوق: `box-sizing: border-box` في كل مكان. الفيض الأفقي يأتي غالبًا من عروض ثابتة، أو كلمات طويلة (`overflow-wrap: anywhere`)، أو صور بلا `max-width: 100%`.
6. التراكب: `z-index` يعمل داخل سياق تراكب فقط، و`transform` و`opacity` الأقل من 1 والتموضع تنشئ سياقات جديدة.
7. الخصائص المنطقية (`margin-inline-start` و`padding-inline` و`inset-inline`) تجعل ملف أنماط واحدًا يخدم العربية من اليمين والإنجليزية من اليسار.
8. خصوصية منخفضة: الأصناف بدل المعرّفات، ولا `!important` خارج الأدوات المساعدة، ومتغيرات CSS للألوان والمسافات.
9. الحركة: حرّك `transform` و`opacity` فقط، واحترم `prefers-reduced-motion`.

## شكل الجواب
كود CSS مع HTML الذي يحتاجه، وسطر عن دعم المتصفحات عند الحاجة.

## ما أحتاجه منك
- الكود الحالي أو وصف التخطيط المطلوب، والمتصفحات أو الأجهزة المستهدفة.

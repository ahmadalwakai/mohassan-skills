كود Java واضح يستفيد من أنواع اللغة ومكتباتها القياسية، ويُختبر بـ JUnit.

## الخطوات
1. حدّد إصدار JDK (يفضّل إصدار LTS مثل 17 أو 21) وأداة البناء Maven أو Gradle.
2. صمّم بالكائنات بقدر الحاجة: واجهات للسلوك، وتركيب بدل وراثة عميقة.
3. المجموعات: List للترتيب، وSet لعدم التكرار، وMap للمفاتيح، وStreams للتحويلات المقروءة.
4. الاستثناءات: التقط ما تستطيع معالجته فقط، واستخدم try-with-resources للموارد.
5. NullPointerException: تحقق من القيم الواردة، واستخدم Optional للقيم التي قد تغيب.
6. Spring Boot: طبقات Controller ثم Service ثم Repository، وحقن التبعيات عبر الباني، وإعدادات في application.yml.
7. JPA: انتبه لـ N+1 وحدّد fetch المناسب، واستخدم الترحيل بـ Flyway أو Liquibase.
8. اختبر بـ JUnit 5 وMockito، وشغّل mvn test أو gradle test قبل الدمج.

## شكل الجواب
الكود المصحح أو المقترح مع شرح مختصر، والأوامر اللازمة، وطريقة التحقق.

## ما أحتاجه منك
- إصدار Java وأداة البناء.
- الكود ورسالة الخطأ كاملة.
- ما الذي يجب أن يفعله البرنامج.

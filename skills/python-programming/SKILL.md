كود Python والسكربتات والتحزيم وأسئلة اللغة.

## الخطوات
1. استهدف إصدارًا حاليًا من Python 3 واذكر أدنى إصدار يحتاجه الكود. بيئة افتراضية لكل مشروع (`python -m venv venv`)، والاعتماديات مثبتة في `requirements.txt` أو `pyproject.toml` مع ملف قفل.
2. كود اصطلاحي: `pathlib` للمسارات، ومديرو السياق (`with`) للملفات والأقفال، وf-strings، والـ comprehensions للتحويلات البسيطة، و`dataclasses` أو `TypedDict` للبيانات المنظمة، وتلميحات الأنواع على الدوال العامة.
3. افتح الملفات النصية بـ `encoding="utf-8"`، وهذا مهم للنص العربي. واستخدم وحدة `csv` أو pandas لملفات CSV و`json` لملفات JSON، ولا تحللها بـ split أبدًا.
4. الأخطاء: التقط استثناءات محددة، ولا تكتب `except:` مجردة أبدًا؛ ودع غير المتوقع يظهر مع تتبعه؛ واستخدم `logging` بدل الطباعة في أي برنامج يعمل طويلًا.
5. الأداء: قِس أولًا (`timeit` و`cProfile`). وفضّل الدوال المدمجة وعمليات pandas أو NumPy المتجهة على حلقات Python للبيانات الكبيرة، والمولّدات للتدفقات، و`asyncio` أو الخيوط للعمل المقيد بالإدخال والإخراج، و`multiprocessing` للعمل المقيد بالمعالج.
6. السكربت يحصل على دالة `main()` و`if __name__ == "__main__":` و`argparse` للخيارات.
7. الاختبارات بـ pytest: دوال صغيرة، وfixtures للإعداد، وسلوك واحد لكل اختبار.
8. أي سكربت يحذف ملفات أو يكتب فوقها يحصل على خيار تجربة جافة وفحص صريح للمسار.

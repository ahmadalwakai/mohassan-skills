كود TypeScript وJavaScript وأنواعه وسلوك اللغة.

## الخطوات
1. فضّل TypeScript في الوضع الصارم. ونمذج البيانات بدقة: اتحادات حرفية للحالات، واتحادات مميَّزة بدل كثرة الحقول الاختيارية، و`unknown` بدل `any` عند الحدود، يُضيَّق بحرّاس الأنواع أو بمدقق مخطط (zod أو ما يشبهه) للمدخلات الخارجية.
2. `interface` و`type` يصفان شكل الكائنات. الواجهات تندمج وتتوسع، والأسماء المستعارة للأنواع تعبّر أيضًا عن الاتحادات والتقاطعات والأنواع المحوَّلة. واعتمد عرفًا واحدًا في المشروع.
3. غير المتزامن: انتظر كل promise أو أعده، ولا تتركه معلقًا أبدًا. شغّل الاستدعاءات المستقلة بـ `Promise.all`، واستخدم `Promise.allSettled` حين يُقبل الفشل الجزئي، وأضف مهلًا زمنية بـ `AbortController`، وتجنب await داخل حلقة حين تكون الاستدعاءات مستقلة.
4. الأخطاء: ارمِ كائنات Error، واحفظ السبب (`new Error(message, { cause })`)، وعالج الأخطاء حيث يمكن فعل شيء حيالها.
5. القيم: استخدم `===`؛ والأعداد العشرية غير دقيقة (0.1 + 0.2)، فخزّن المال أعدادًا صحيحة بأصغر وحدة؛ واحفظ التواريخ بتوقيت UTC ونسّقها عند العرض بـ `Intl`.
6. الوحدات: ES modules للكود الجديد؛ ولا آثار جانبية في المستوى الأعلى للوحدة؛ واستورد الأنواع بـ `import type`.
7. فضّل عدم التغيير: `const`، والنشر أو `structuredClone` بدل تعديل الكائنات المشتركة أو وسائط الدوال.
8. قدّم مقتطفات كاملة قابلة للتشغيل مع الاستيرادات، واذكر بيئة التشغيل (إصدار Node أو المتصفح) حين يعتمد السلوك عليها.

الكشط المسؤول يبدأ بالبحث عن API رسمية، ويحترم شروط الموقع وحدوده، ويجمع فقط ما يحتاجه.

## الخطوات
1. ابحث أولًا عن API أو ملف بيانات رسمي؛ هذا أثبت وأسلم من الكشط.
2. اقرأ شروط الموقع وملف robots.txt، ولا تجمع بيانات شخصية أو محمية بحقوق دون إذن.
3. افحص الصفحة: إن كانت البيانات في HTML الأصلي فاستخدم requests مع BeautifulSoup، وإن ظهرت بـ JavaScript فابحث عن طلب الشبكة الذي يجلبها في أدوات المطور، أو استخدم Selenium.
4. اختر المحددات الثابتة (معرّفات وسمات data) لا مواضع العناصر.
5. أبطئ الطلبات: ثانية أو أكثر بين الطلبات، وعدد محدود في التوازي، وعرّف User-Agent واضحًا.
6. عالج الأخطاء: إعادة المحاولة مع تأخير متزايد، وتسجيل الصفحات الفاشلة.
7. للمواقع الكبيرة: Scrapy مع خطوط معالجة ونقاط استئناف.
8. احفظ النتائج في CSV أو قاعدة بيانات، ونظّف القيم ووحّد الصيغ.

## شكل الجواب
كود مختصر بلغة Python، وشرح المحددات، وتنبيهات قانونية وأخلاقية خاصة بالحالة.

## ما أحتاجه منك
- الموقع ونوع البيانات المطلوبة.
- هل الصفحة ثابتة أم تُحمَّل بـ JavaScript؟
- الكمية والتكرار المطلوبان.
